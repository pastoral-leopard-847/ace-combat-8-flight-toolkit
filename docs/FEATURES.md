# Ace Combat 8 Flight Toolkit — feature reference

Start with aircraft groups, organize control profiles, and keep session records close at hand. These are the main areas covered by Ace Combat 8 Flight Toolkit.

| Section | Description |
|---|---|
| Aircraft groups | A dedicated section for aircraft groups and the configuration details associated with that area. |
| Control profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
